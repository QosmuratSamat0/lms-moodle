# Mini-Moodle Project Proposal

## 1. Project Relevance

Mini-Moodle is a lightweight Learning Management System designed for small university groups and courses that need core academic workflows without complex setup. Many existing LMS platforms provide huge functionality but require heavy configuration, large infrastructure, and have a steep learning curve. Our project focuses on the most common daily needs: managing courses, assignments, submissions, and grading in a clear and fast way.

## 2. Target Users

### Students

- Join courses, view assignments and deadlines
- Submit homework and track submission status
- See grades and teacher feedback

### Teachers

- Create and manage courses
- Publish assignments with deadlines and max points
- Review student submissions, grade them, and leave feedback

### Admin

- Manage user accounts and roles (student/teacher/admin)
- Monitor basic system state (active users, courses)
- Resolve access issues (e.g., role changes)

## 3. Competitor Analysis

### Moodle

**Pros:** very powerful, flexible, huge plugin ecosystem
**Cons:** complex UI, heavy configuration, can be overwhelming for small groups
**Our difference:** minimal setup + focused core features only

### Google Classroom

**Pros:** easy to start, good integration with Google services
**Cons:** limited customization and grading workflows, depends on Google ecosystem
**Our difference:** clearer grading/submission model and role-based access

### Canvas

**Pros:** modern interface, strong course management
**Cons:** often paid/enterprise-oriented, may be too much for small use cases
**Our difference:** small, lightweight, easy to deploy and extend

## 4. Planned Features (High-Level)

### Core features (MVP scope)

- Authentication and roles (student/teacher/admin)
- Courses: create course (teacher), join/enroll (student), list courses
- Assignments: create assignment (teacher), list assignments (student/teacher)
- Submissions: submit assignment (student), view submissions (teacher)
- Grading: teacher grades a submission, student sees score and feedback

### Future features (after milestone)

- Chat/messaging inside a course
- Notifications (deadlines, graded submission)
- File storage improvements and plagiarism checks
- Mobile client improvements
